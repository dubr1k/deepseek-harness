# Установка сборки форка на macOS

Для Mac с Apple Silicon. Образ DMG содержит готовый Desktop, Codex для входа через ChatGPT, четыре роли агентов, Project Passport, Workspace tools, Task templates и навык Graphify.

1. Откройте DMG. Перетащите **DeepSeek Harness (Pi 1.5.2).app** в **Applications**. Для установки только своему пользователю можно скопировать приложение в `~/Applications`. Сохраните имя приложения.
2. Закройте открытые экземпляры Harness. В образе запустите **Настроить Harness.command** от имени пользователя, который будет работать в Harness. На новом Mac скрипт создаст профиль Desktop. При обновлении он сохранит резервную копию профиля в `~/.dsh/backups`. Для нескольких пользователей повторите этот шаг в каждой учётной записи.
3. Извлеките образ и запустите приложение из Applications. Для моделей GPT используйте свой аккаунт ChatGPT через Codex. Для входа из интерфейса Harness требуется официальный Codex CLI в окружении этого пользователя.

На новом профиле настройка выполняется без установки системных Node.js и pnpm. В существующем профиле менеджер пакетов может загрузить пользовательские зависимости. Для Firecrawl установите и настройте собственный MCP-сервер в `~/.codex/config.toml` до запуска настройки. Для Graphify нужен отдельный CLI. Пример маршрута OpenRouter лежит в `Integrations/payload/graphify/openrouter-provider.example.json`. OpenDesign подключается при наличии локального CLI.

У приложения локальная подпись ad-hoc. Для запуска на управляемых компьютерах действуют правила вашей организации. [Проверка приложений в macOS](https://support.apple.com/en-us/102445).

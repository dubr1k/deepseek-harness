# Task templates: как пользоваться

Это библиотека заготовок запросов внутри DSH. Шаблон хранит текст и поля вида `{{Goal}}`; при выборе плагин показывает отдельные поля, подставляет значения и позволяет скопировать готовый запрос. Он не запускает инструменты, не выбирает проект и не отправляет сообщение автоматически.

## Добавленные шаблоны

| Шаблон | Когда использовать | Поля |
|---|---|---|
| Project re-entry | Вернуться в проект и понять состояние | Goal — ближайшая цель |
| Safe implementation | Реализовать изменение с проверкой результата | Task; Acceptance criteria |
| Pre-commit review | Собрать diff, запустить проверки и встроенного ревьюера | Focus — на что обратить внимание |
| Research with Firecrawl | Собрать источники и сохранить исследовательские заметки | Question; Sources or domain |
| Work handoff | Сохранить передачу работы к следующему заходу | Next goal |
| Architecture with Graphify | Разобраться в связях существующего проекта | Architecture question |

1. Откройте **Task templates** в боковом меню и выберите шаблон в **Choose a template**.
2. Заполните появившиеся поля. Например, для Safe implementation: Task — «Добавить поиск по названию проекта», Acceptance criteria — «Поиск без учёта регистра; пустой запрос показывает все проекты».
3. Прочитайте **Prepared task**. Пока обязательное поле пусто, **Copy** недоступна.
4. Нажмите **Copy**, вернитесь в беседу нужного проекта, вставьте текст и отправьте обычной кнопкой Send. Именно выбранная беседа определяет рабочий проект.

Параметры шаблона заполняются заново при следующем выборе; одинаковые `{{параметры}}` имеют одно общее поле. Названия английские, задания русские.

## Свой шаблон

В **Add template** задайте **Name** и **Template text**, например: «Проверь {{file}} на {{problem}}». Нажмите **Save template**. Появятся два поля file и problem; никаких специальных команд или программирования не требуется.

Библиотека общая для устройства и хранится локально в интерфейсе приложения. Сам плагин не синхронизирует её через GitLab, не привязывает к workspace и пока не предоставляет редактирование/удаление или импорт JSON. Наши шесть заготовок сохранены отдельно в [templates/library.json](../templates/library.json) для переноса: на другой машине их можно добавить через ту же форму. Существующие пользовательские шаблоны не заменены.

# Workspace tools

English | [中文](README.zh.md)

This plugin provides Handoff, Pre-commit review and Research notebook. Header actions use transparent buttons. Reviews and checks require explicit actions; saved records remain in local storage. The integration kit pins version 1.0.4.

Install through the [integration kit](../../README.ru.md), which copies this bundle into the target profile and records a backup. Remove this plugin through DSH Plugins and restart to disable its contributions. Removal does not erase existing sessions or stored records.

Native review on DSH 0.2.2-rc.2 resolves the tool’s named activation for its calling root and checks that it matches the guarded child. Missing or mismatched identities stop review. Cancellation uses host-owned interrupt authority. Existing stored records are retained.

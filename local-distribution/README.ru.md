# DeepSeek Harness — наш билд stable-2026.11.19-1

Это интеграционный комплект для **macOS ARM64** на базе оригинального подписанного **DSH Desktop 0.2.2-rc.5**. «Stable» — название нашей закреплённой конфигурации; сам DSH остаётся developer preview. Ветка `release/codex-integrations` форка [dubr1k/deepseek-harness](https://github.com/dubr1k/deepseek-harness/tree/release/codex-integrations) содержит исходники Harness 0.2.2-rc.5 и этот установочный комплект. В сборке из исходников форка используется pi-ai 1.5.2. Подписанный Desktop из этого комплекта поставляется с pi-ai 1.3.0. Плагин Codex поддерживает обе версии.

## Как установить

1. Скачайте официальный ZIP по ссылке `baseArchive.originalUrl` в versions.json, сверьте SHA-512 из `baseArchive.sha512Base64`, распакуйте и перенесите `DeepSeek Harness.app` в `/Applications`. Проверьте подпись командой `codesign --verify --deep --strict "/Applications/DeepSeek Harness.app"`.
2. Клонируйте этот форк и переключитесь на `release/codex-integrations`. Из каталога `local-distribution` выполните `shasum -a 256 -c SHA256SUMS`.
3. На новой машине один раз запустите DSH и закройте его. При закрытом приложении запустите **Configure DSH.command из этого каталога**. Он проверит версию приложения, сохранит резервную копию профиля и установит закреплённые плагины, роли и навык Graphify.
4. Откройте DSH и войдите в Codex своим аккаунтом. Для Firecrawl требуется существующая секция `mcp_servers.firecrawl` в `~/.codex/config.toml` и установленная команда сервера; Graphify CLI устанавливается отдельно.

Установщик не заменяет ваши личные инструкции, сессии или авторизацию. Ключи, OAuth, `.env` и переписки в комплект не входят. Пример необязательных инструкций: `config/AGENTS.example.md`. Дополнительные навыки из `skillsInventory` в versions.json перечислены для справки, их содержимое не поставляется.

Graphify использует явный маршрут `openrouter` → `https://openrouter.ai/api/v1`, модель `google/gemini-3.8-flash`; пример конфигурации без ключа — `payload/graphify/openrouter-provider.example.json`. Учётные данные остаются локально. OpenDesign подключается при наличии `~/.local/lib/open-design-shared/od.cjs` либо пути из `OPEN_DESIGN_CLI`.

## Изображения: использование и ограничения

Для создания нажмите **Create image**, задайте параметры и описание, затем **Add to message** и отправьте сообщение. Для изменения нажмите **Edit image** возле результата, задайте правку и параметры, добавьте их в сообщение и отправьте. Выбранное изображение передаётся явной ссылкой; существующий черновик сохраняется. Эти действия не меняют глобальные настройки.

В обновлённом Desktop rc.2 проверены создание Flare / Low и редактирование выбранного изображения с отображением результата в чате: красный круг заменён на синий. Запрос 1024×1024 вернул 1536×1024; фактические размеры и предупреждение показаны. Sunburst также вернул изображение в отдельной прямой проверке backend. Выбор GPT Image 2 доступен, но отдельная проверка этой модели в данном выпуске не заявляется.

**Запрошенный размер не гарантирует размер результата.** В прямых проверках Flare запросы 1152×768 и 3840×2160 вернули 1536×1024. Custom size и большие пресеты следует считать экспериментальными; ориентируйтесь на размеры под готовым изображением. Доступность моделей, качество и Fast зависят от аккаунта и backend. Запрос может быть отклонён модерацией.

Предыдущие проверки rc.3: [evidence/build-2026.11.14.json](evidence/build-2026.11.14.json). Результаты исправления SSE в rc.2: [evidence/build-2026.11.12.json](evidence/build-2026.11.12.json). Предыдущие проверки изображений: [evidence/build-2026.11.11.json](evidence/build-2026.11.11.json). Исторические проверки базовых ролей и MCP сохранены в `verification.json`; они не являются новым прогоном этого выпуска. Перенос на полностью чистую машину и новый семантический прогон Graphify не выполнялись. В Desktop rc.2 проверены Firecrawl scrape и авторизация OpenDesign Cloud; работа с проектами OpenDesign Cloud не проверялась.

Для отката закройте DSH, сохраните текущий профиль отдельно и верните `~/.dsh/backups/before-codex-kit-<timestamp>` на место `~/.dsh/profiles/desktop`. Не заменяйте хранилища сессий и авторизации. Копия прежнего навыка Graphify при его наличии находится в `graphify-skill` внутри этой резервной копии. Порядок обновления базы: [docs/UPDATING.md](docs/UPDATING.md).

В rc.2 повторно проверены семь включённых моделей Codex с Long Context выключенным и включённым, включая replay инструментов, продолжение и автоматический Basic compaction: 14 сценариев, 70 успешных HTTP-запросов. Порог compaction уменьшен только в изолированных тестах; заполнение полного производственного окна не проверялось. Максимум Long Context согласован с текущим каталогом провайдера: 872 000 токенов. Установщик удаляет устаревшую внешнюю зависимость `dsh-subagent-codex`, которая подменяла штатные пакеты rc.2; нативные роли сохранены.

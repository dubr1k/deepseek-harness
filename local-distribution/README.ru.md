# DSH + Codex для macOS ARM64

Комплект использует неизменённое подписанное приложение DSH 0.2.2-rc.1, Codex-плагин 0.3.4-rc.3 (3343d6f), нативные роли DSH, Firecrawl MCP и локальный навык Graphify. Экспериментальное новое ядро и Центр расширений сюда не входят.

1. Перенесите DeepSeek Harness.app в Applications. При первом использовании запустите и закройте приложение, чтобы создать профиль.
2. Закройте DSH и запустите Configure DSH.command из этого комплекта. Настройщик сохранит предыдущий профиль и обновит Codex и роли.
3. Запустите DSH. Авторизация Codex остаётся локальной; на новом компьютере войдите в свой аккаунт.

Firecrawl импортируется из вашей существующей секции mcp_servers.firecrawl в ~/.codex/config.toml. Требуется установленная команда сервера (для npx — Node.js). Graphify использует установленный CLI; его установка и провайдеры не меняются. Ключи, OAuth и переписки в комплект не входят.

Субагенты работают штатными spawn/Agent Presets DSH: Luna — разведка, Terra — реализация, Sol — сложные задачи, Astra — независимое ревью. Внешний Codex subprocess bundle отключается; обычные subagent и subagent_fork DSH остаются.

Откат: закрыть DSH; сохранить текущий профиль отдельно и вернуть каталог ~/.dsh/backups/before-codex-kit-<timestamp> на место ~/.dsh/profiles/desktop. Не заменять ~/.dsh/sessions и хранилища авторизации.

Fast запрашивает priority; предоставление ускоренного обслуживания зависит от backend.
